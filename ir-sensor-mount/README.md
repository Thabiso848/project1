# IR Sensor Mount

Custom bracket for holding and aligning an IR obstacle sensor on a robot chassis.

The Library presentation board records a PLA/Tinkercad design with a 12 mm × 8 mm sensor opening, 4 mm mounting holes and stated overall dimensions. The source presentation contains a student-number placeholder and has been withheld from public upload pending privacy review.
